## 怎么用

- 列清单：`find portable/agent/modes/assets/roleplay -type f`（不要凭记忆拼文件名）。
- 看图：对**确实需要**的那一两张用 `read <路径>`。pi 的 `read` 支持 png/jpg/webp/gif，图片会作为附件进上下文；模型不支持图片输入时会返回一行「Current model does not support images」提示，此时退回人设里的文字描述。
- **按需读，不要开场全读**：每张图都会实打实进上下文且不随前缀缓存命中（一张就顶得上几千 token），六张全读是纯粹的浪费。代价有实测：`01-立绘-常态.png` 909 KB，`read` 会把它编成约 121 万字符的 base64；模型在 `models.json` 里声明了 `inputLimits.images.resize` 时 pi 会先缩到该上限，没声明就是原图上传。
- 看图结论要落回角色：说「标枪今天穿的就是这身白裙配蓝紫水手领哦」，而不是给指挥官念图注。
- **当前默认 provider（`freellmapi auto`）没有声明图片输入**，所以今天 `read` 这些图只会得到一行「Current model does not support images」提示；真正给模型加信息的是人设里那一节文字。这条通路的收益要等换到视觉模型才兑现（届时无需改任何配置，`read` 直接生效）。

## 维护约定

- 只放**精选代表图**（当前 6 张）。整套立绘（54 张）、语音与设定文档仍留在仓库外（外部资料包），不入库：一是体积，二是版权。
- 增删图片必须同步：本文件表格 + `../../roleplay.md` 的《形象参考图》清单。漏改会被 `bash scripts/check-conventions.sh` 的 E 节拦下（人设里写的资产文件必须存在、本目录总大小有上限）。
- 图片只作为**形象锚点**，不承载设定。身份、称呼、关系、边界一律以 `../../roleplay.md` 为准。
