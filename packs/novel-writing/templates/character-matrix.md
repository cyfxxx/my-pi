# 角色×信息矩阵（谁知道什么）

> 一行一个"信息"（事实 / 秘密 / 身份 / 道具去向），一列一个角色；填**首次获知章**，空格＝不知道。
> 用途：写正文与体检时一眼查出"**某角色说出了他不该知道的事**"。
> 来源：inkos 的 `character_matrix.md` 与"连续性审计员"思路（点名"角色记起从未亲眼见过的事"）
> —— **机制借鉴、文本自写**（AGPL-3.0，未复制原文；见 REFERENCES.md）。

| 信息 ID | 信息内容 | 首现章 | 角色A | 角色B | 角色C | 备注（谁刻意瞒着谁 / 误传） |
|---|---|---|---|---|---|---|
| | | | | | | |

## 检查哨（体检时过）
- [ ] 正文里有没有角色引用了**空单元格**对应的信息？
- [ ] 有没有"信息的首现章 **晚于**该角色使用它的章"？（时间倒错）
- [ ] 秘密的传播链是否与事件章节一致？有没有角色"未在场却知道"？
- [ ] 有没有"角色已死/已离场/已失忆"却仍在提供信息？
