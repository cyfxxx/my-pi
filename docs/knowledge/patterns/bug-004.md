# 失败模式：重启后**白跑一个模型回合**

**来源**：`docs/BUG-REPLAYS.md` 第 4 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
重启后**白跑一个模型回合**

**根因（WHY）**
没有在途任务（切模式/换模型/切会话）也被"请继续"唤醒，实测还会让模型凭空开工

**确切命令序列**（复现/回归都靠它）
```bash
`npx vitest run custom/core/__tests__/restart-intent.test.ts`；真 pty 场景的"切模式零回合"断言（`PI_GOLDEN_SCENARIO=1 node scripts/test-scenario-mode-restart.mjs`）
```

**怎么发现它（指纹）**
会话文件在重启后多出 user/assistant 条目；`daily-health` 里冷启动与未命中异常

**含确切语法的解法**
`custom/core/restart-intent.ts`（意图 → 盘面尾部 → `PI_RESTART_RESUME`）+ 两条注入通道 + 接线测试 + 场景断言
