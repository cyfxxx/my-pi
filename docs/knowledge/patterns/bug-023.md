# 失败模式：**为「模拟缺工具」清空 PATH ⇒ 连自己的工具一起弄没**

**来源**：`docs/BUG-REPLAYS.md` 第 23 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**为「模拟缺工具」清空 PATH ⇒ 连自己的工具一起弄没**

**根因（WHY）**
报 timeout/grep: command not found，看起来像被测代码失败，其实是测试方法错

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'env PATH="$(dirname $(command -v node))" $(command -v node) scripts/security-scan.mjs --file /tmp/x'`
```

**怎么发现它（指纹）**
同一个坑犯了两次，两次都误判成代码有问题

**含确切语法的解法**
**无自动守门**（受限 PATH 只能注入给被测进程；自己的工具用绝对路径）
