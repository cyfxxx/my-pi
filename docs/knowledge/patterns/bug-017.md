# 失败模式：**类型级修复「潜伏未提交」**

**来源**：`docs/BUG-REPLAYS.md` 第 17 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**类型级修复「潜伏未提交」**

**根因（WHY）**
typebox 1.3.x 没有 Type.Null()（只有 Null 常量）⇒「可选 + null」这条最常用路径抛 ReferenceError；而提交门禁走 golden --fast（跳过 tsc）⇒ 修复能一直躺在工作区不被发现

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'node_modules/.bin/tsc --noEmit -p custom/'`
```

**怎么发现它（指纹）**
全量 tsc 才暴露（--fast 不跑它）

**含确切语法的解法**
**全量 tsc**（关键改动后手动补跑；--fast 不覆盖）
