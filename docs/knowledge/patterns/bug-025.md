# 失败模式：**测试把 bug 当契约**

**来源**：`docs/BUG-REPLAYS.md` 第 25 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**测试把 bug 当契约**

**根因（WHY）**
既有测试断言「在租的 worker 也被回收」，于是 bug 长期存活（测试成了它的保护壳）

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'grep -n "shutdown 回收空闲与在租" custom/features/subagent/__tests__/rpc-pool.test.ts'`
```

**怎么发现它（指纹）**
修池 bug 时发现原测试 expect(a.worker.alive).toBe(false) 正是 bug 行为

**含确切语法的解法**
**无自动守门**（改语义前须人工回看断言表达的契约）
