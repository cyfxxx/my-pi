# 失败模式：**多实例串扰**

**来源**：`docs/BUG-REPLAYS.md` 第 8 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**多实例串扰**

**根因（WHY）**
两个 my-pi 同时跑（实测同日出现过两个 supervisor），A 写的重启请求被 B 的 supervisor 执行 → 会话被跨实例重启/续错

**确切命令序列**（复现/回归都靠它）
```bash
`npx vitest run custom/features/autopilot/__tests__/restart-log.test.ts`；`bash scripts/test-supervisor.sh`（ownerPid 认领/不认领两侧）
```

**怎么发现它（指纹）**
`rounds.jsonl` 里出现不属于本实例的 session；用户"重启后跑到了别的会话"

**含确切语法的解法**
写入端带 `ownerPid`（pi 的 ppid）+ supervisor 只认自己的请求（无 ownerPid 的老请求照旧认领）
