# 失败模式：切模式/切回角色扮演会话时**进程直接退出**、模式没换、还注入了一条"系统已重启"（重启其实没发生）

**来源**：`docs/BUG-REPLAYS.md` 第 3 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
切模式/切回角色扮演会话时**进程直接退出**、模式没换、还注入了一条"系统已重启"（重启其实没发生）

**根因（WHY）**
未独立记录（见「是什么」原文）

**确切命令序列**（复现/回归都靠它）
```bash
`bash scripts/test-supervisor.sh`（含 stub CLI 复刻该时序的端到端用例）；`PI_SCENARIO_KEEP=1 node scripts/test-scenario-mode-restart.mjs`
```

**怎么发现它（指纹）**
会话文件里有 `系统已重启` 注入但**后面没有 assistant 回复**；`rounds.jsonl` 里 `lostRestart: true`；终端留下未读的 OSC/DA1 应答乱码

**含确切语法的解法**
① `consumeRestartLog()` 只清 `restartLog` 不动 `action`（跨 TS/bash 契约测试）；② supervisor 的 `lost_restart` 实时检测 + `rounds.jsonl`；③ 真 pty 场景；④ 状态体检 `restart-request-stale` / `notice-undelivered`
