# 失败模式：**防环标记单槽互相覆盖**

**来源**：`docs/BUG-REPLAYS.md` 第 9 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**防环标记单槽互相覆盖**

**根因（WHY）**
两个会话/实例各自自愈时，后写的把先写的防环标记顶掉 → 双方反复放行、来回重启

**确切命令序列**（复现/回归都靠它）
```bash
`npx vitest run custom/features/mode/__tests__/mode-switch.test.ts -t '多会话/多实例'`
```

**怎么发现它（指纹）**
`mode-restart-guard.json` 里只剩一条 key；`rounds.jsonl` 同一会话短时间内多次 restart

**含确切语法的解法**
标记改多键 `{ "<会话>::<模式>": ts }`（旧格式兼容迁移）+ 上限/过期裁剪
