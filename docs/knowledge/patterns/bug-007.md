# 失败模式：功能名拼错（如 `websearch`）→ 该功能静默不注册，模式看起来"没生效"

**来源**：`docs/BUG-REPLAYS.md` 第 7 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
功能名拼错（如 `websearch`）→ 该功能静默不注册，模式看起来"没生效"

**根因（WHY）**
未独立记录（见「是什么」原文）

**确切命令序列**（复现/回归都靠它）
```bash
`node scripts/state-audit.mjs` → `mode-feature-unknown`（error）
```

**怎么发现它（指纹）**
该模式下少了预期工具，但没有任何报错

**含确切语法的解法**
状态体检 `mode-feature-unknown` + 三处真值不漂移守门（功能名 ↔ `ALL_FEATURES` ↔ 注册面基线）
