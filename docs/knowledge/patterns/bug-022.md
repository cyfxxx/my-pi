# 失败模式：**pkill -f 会杀掉自己**

**来源**：`docs/BUG-REPLAYS.md` 第 22 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**pkill -f 会杀掉自己**

**根因（WHY）**
-f 匹配整条命令行，而自己的命令行里就含那个模式 ⇒ 命令被打断、后续步骤静默不执行

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'ps -o args= -p $$'`
```

**怎么发现它（指纹）**
整条 bash 调用被自己 SIGTERM（killed by signal: SIGTERM）

**含确切语法的解法**
**无自动守门**（先看清自己的命令行是否含该模式；改用精确 PID/作业管理）
