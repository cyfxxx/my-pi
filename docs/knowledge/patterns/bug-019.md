# 失败模式：**状态文案会「说谎」**

**来源**：`docs/BUG-REPLAYS.md` 第 19 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**状态文案会「说谎」**

**根因（WHY）**
not-scanned 曾一律打印「本机没有 ClamAV/YARA」，而引擎其实装着、真实原因是「文件不存在」⇒ 写死的解释性文案会随环境从「保守」变成「撒谎」

**确切命令序列**（复现/回归都靠它）
```bash
`node scripts/security-scan.mjs --file /tmp/不存在的文件`
```

**怎么发现它（指纹）**
端到端演示时发现文案与事实不符

**含确切语法的解法**
文案已改为指向真实原因 + 打印 原因：…；**无自动守门**
