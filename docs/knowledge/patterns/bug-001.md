# 失败模式：切了模式、重启后没生效

**来源**：`docs/BUG-REPLAYS.md` 第 1 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
切了模式、重启后没生效

**根因（WHY）**
`modes.json` 里的全局 `current` 被任何 git 操作（checkout/stash/pull）静默退回 `full`

**确切命令序列**（复现/回归都靠它）
```bash
`node scripts/state-audit.mjs` → `modes-legacy-current`（info）；`bash scripts/check-conventions.sh`（运行时状态不入库）
```

**怎么发现它（指纹）**
`git status` 后模式变了；`modes.json` 里出现 `current` 字段

**含确切语法的解法**
`check-conventions`（状态不入库）+ 状态体检 `modes-legacy-current`；模式状态已迁到 gitignored 的 `modes-sessions.json`
