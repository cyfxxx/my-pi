# 失败模式：**PowerShell 参数集互斥参数写成一条 ⇒ 报错指向参数名而非真因**

**来源**：`docs/BUG-REPLAYS.md` 第 35 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**PowerShell 参数集互斥参数写成一条 ⇒ 报错指向参数名而非真因**

**根因（WHY）**
`Set-Disk -Number N -IsOffline $false -IsReadOnly $false` 报 `无法使用指定的命名参数解析参数集 / AmbiguousParameterSet`。真因是 **`Set-Disk` 的 `-IsOffline` 与 `-IsReadOnly` 分属不同参数集**（`ByNumber` 与 `ByNumberAttributes`，该 cmdlet 共 12 个参数集），不能同条指定——而报错文案只谈"参数集"，不告诉你**是哪两个**互斥，于是容易误判成"`-Number` 不对/权限不足/参数拼错"。同类隐患：`-WhatIf` 不被 `Set-Disk`/`New-Partition` 支持（想预演时会再撞一次）

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'powershell -c "Set-Disk -Number 99 -IsOffline $false"'`（应报"找不到对象"而非"参数集"，证明绑定先于存在性检查）；正确写法必须拆开成两条：`Set-Disk -Number $n -IsOffline $false` 与 `Set-Disk -Number $n -IsReadOnly $false`；可用参数集查证：`bash -c 'powershell -c "(Get-Command Set-Disk).ParameterSets ｜ % { \$_.Name }"'`（把 ｜ 换成真竖线）
```

**怎么发现它（指纹）**
报 `AmbiguousParameterSet`；同一条命令拆成两行后立刻通过；用不存在的磁盘号 99 可复现并区分两类失败——报"找不到磁盘"说明**参数绑定已通过**，报"参数集"才是拼错

**含确切语法的解法**
**已写进 `docs/operations/VOLUME-REBUILD.md` 的格式化步骤**（命令拆开并注明原因）；无自动守门（属 PowerShell 用法约束，只出现在手动运维流程里）
