# 失败模式：**守门脚本的开关组合会把它变成"只测量"（虚假绿）**

**来源**：`docs/BUG-REPLAYS.md` 第 39 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**守门脚本的开关组合会把它变成"只测量"（虚假绿）**

**根因（WHY）**
`scripts/dsh-baseline.sh` 最初把参数写成三选一的位置参数（`--check` / `--update` / `--tools`／`--prompt`），于是 `--prompt --check` 只取第一个开关、**丢掉 `--check`** —— 命令看起来在守门，实际只打印测量值并 exit 0；此时改动被守门的源文件也不会报错。这类失效能骗过"我跑过守门了"的自述，属本项目最忌讳的虚假绿

**确切命令序列**（复现/回归都靠它）
```bash
`printf "\n<!-- probe -->\n" >> portable/agent/APPEND_SYSTEM.md && bash scripts/dsh-baseline.sh --prompt --check; echo "exit=$?"; git checkout -- portable/agent/APPEND_SYSTEM.md`（修前 exit=0；修后应 exit=1 并点名"渲染文本 sha256 变了 / 源文件变了 / 段内容变了"三条）
```

**怎么发现它（指纹）**
未改任何文件时 `--prompt --check` 与 `--prompt` 输出**完全一样**且都 exit 0；改一行源文件后 `--prompt --check` 仍 exit 0（应 1）

**含确切语法的解法**
**已修（2026-10-15，分支 `feat/base-switch-dsh`）**：参数解析改为**正交可组合**（`--check`／`--update` 与 `--tools`／`--prompt` 分开解析），并显式拒绝"`--check` 与 `--update` 同时给"；反证：改源文件 ⇒ exit 1 且三条漂移全部点名，`git checkout` 复原 ⇒ exit 0
