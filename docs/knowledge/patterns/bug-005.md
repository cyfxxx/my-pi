# 失败模式：入口漂移

**来源**：`docs/BUG-REPLAYS.md` 第 5 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
入口漂移

**根因（WHY）**
`dev.sh` 不注入人设（supervisor 注入了），人设文件缺失时**静默**不注入

**确切命令序列**（复现/回归都靠它）
```bash
`node scripts/state-audit.mjs` → `mode-persona-missing`（error）；`bash scripts/test-supervisor.sh` 的人设注入用例
```

**怎么发现它（指纹）**
同一模式在 dev 与 my-pi.sh 下行为不同；人设文件被改名/删除

**含确切语法的解法**
状态体检 `mode-persona-missing`（error，daily-health 会 alert）+ `lib-mode.sh` 共用解析
