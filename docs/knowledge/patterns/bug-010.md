# 失败模式：**写盘失败静默退出**

**来源**：`docs/BUG-REPLAYS.md` 第 10 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**写盘失败静默退出**

**根因（WHY）**
`admin_restart`/`admin_set_model`/`admin_switch_session` 请求写不下去仍 `shutdown` → 进程没了、配置/会话也没变

**确切命令序列**（复现/回归都靠它）
```bash
`npx vitest run custom/features/autopilot/__tests__/admin-tools.test.ts -t '写盘失败'`；`npx vitest run custom/features/mode/__tests__/mode-autopilot-restart.test.ts -t '写盘失败'`
```

**怎么发现它（指纹）**
无 state.json 变化却退出了；下一次启动配置未生效

**含确切语法的解法**
三个工具 + mode 的 `requestModeRestart` 一律"写失败就不退出 + 明确文案"
