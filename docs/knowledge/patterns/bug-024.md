# 失败模式：**新引入一种「我写的文件格式」⇒ 必须同时引入校验它的守门**

**来源**：`docs/BUG-REPLAYS.md` 第 24 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**新引入一种「我写的文件格式」⇒ 必须同时引入校验它的守门**

**根因（WHY）**
非法 JSON 一路提交进仓库（文档链接只查 md、约定守门只查计数、死导出只查 TS）

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'node -e "JSON.parse(require(String.fromCharCode(102,115)).readFileSync(\"packs/security-baseline/tiers.json\",\"utf8\"))"'`
```

**怎么发现它（指纹）**
补排除项时被 json.loads 抓到（此前已据此写了文档）

**含确切语法的解法**
**已有守门**：scripts/check-conventions.sh 的 JSON 语法守门（packs/scripts/sync 下的 .json）
