# 失败模式：模式解析"第 3 轮工厂执行后漂回 full"

**来源**：`docs/BUG-REPLAYS.md` 第 2 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
模式解析"第 3 轮工厂执行后漂回 full"

**根因（WHY）**
`PI_AGENT_MODE_SOURCE` 从 `file` 被翻成 `env`，此后把首轮值当外部注入钉死

**确切命令序列**（复现/回归都靠它）
```bash
`npx vitest run custom/features/mode/__tests__/mode-switch.test.ts -t '多轮工厂执行不漂移'`
```

**怎么发现它（指纹）**
同一进程内多轮工厂执行（/reload、/new、会话切换）后模式与磁盘不一致

**含确切语法的解法**
`mode-switch.test.ts` 的三轮回归 + `resolveStartupMode()` 单一写入点
