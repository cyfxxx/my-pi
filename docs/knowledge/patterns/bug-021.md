# 失败模式：**形参名与导入的模块名同名** ⇒ 块内引用模块会打到形参上；且「补一个 import」完全无效（导入同样被形参遮蔽）

**来源**：`docs/BUG-REPLAYS.md` 第 21 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**形参名与导入的模块名同名** ⇒ 块内引用模块会打到形参上；且「补一个 import」完全无效（导入同样被形参遮蔽）

**根因（WHY）**
未独立记录（见「是什么」原文）

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'grep -n "function .*(path" scripts/security-scan.mjs'`
```

**怎么发现它（指纹）**
运行时 path.join is not a function（我先误判成导入缺失，白费 1 轮）

**含确切语法的解法**
**无自动守门**（scripts/*.mjs 不进 tsc -p custom/；正解=块内不引用那个名字）
