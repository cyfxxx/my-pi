# 失败模式：**并行时「运行中的 worker 被池回收」**

**来源**：`docs/BUG-REPLAYS.md` 第 18 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**并行时「运行中的 worker 被池回收」**

**根因（WHY）**
shutdown() 连 leased 一起 dispose ⇒ 回退 spawn（无投递通道）⇒ 中途投递的消息永远停在未读

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'node_modules/.bin/vitest run custom/features/subagent/__tests__/rpc-pool-shutdown.test.ts'`
```

**怎么发现它（指纹）**
并行子代理投递后消息停在「未读 1/1」

**含确切语法的解法**
**已修 + 回归测试挡住**（改前 1 failed / 改后 4 passed）
