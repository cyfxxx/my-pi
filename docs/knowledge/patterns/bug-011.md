# 失败模式：**归属判定的误伤**

**来源**：`docs/BUG-REPLAYS.md` 第 11 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**归属判定的误伤**

**根因（WHY）**
加了 ownerPid 隔离后，别人的重启日志在本实例退出时被记成 `lost_restart`（"请求被吞"）→ 每日体检假告警

**确切命令序列**（复现/回归都靠它）
```bash
`bash scripts/test-supervisor.sh`（"别人的日志 → 不算丢"三例）
```

**怎么发现它（指纹）**
`rounds.jsonl` 里 `lostRestart:true` 而 `adminAction` 为空、且会话属于别的实例

**含确切语法的解法**
`detect_lost_restart` 增加第 5 个判据"日志的 ownerPid 必须是本实例"；`read_admin_action` 多输出一个 `LOWNER` 字段
