# 失败模式：**注释里「两个星号紧跟斜杠」⇒ 块注释被提前关闭**

**来源**：`docs/BUG-REPLAYS.md` 第 20 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**注释里「两个星号紧跟斜杠」⇒ 块注释被提前关闭**

**根因（WHY）**
报错行看起来完全正常（它是被挤出注释的普通文本）⇒ 表现为 ReferenceError: xxx is not defined

**确切命令序列**（复现/回归都靠它）
```bash
`bash -c 'node --check scripts/security-baseline.mjs'`
```

**怎么发现它（指纹）**
写脚本时运行时崩（本会话白费 3 轮；另一次 440 行实现同源崩）

**含确切语法的解法**
**无自动守门**（靠写注释时自查 + node --check）
