# 失败模式：**诊断工具自身的盲区

**来源**：`docs/BUG-REPLAYS.md` 第 15 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**诊断工具自身的盲区

**根因（WHY）**
JSON 转义吃掉分段结构**：`systemTextOf()` 对字符串 `content` 也无条件 `JSON.stringify` → 真实换行被转义成字面量 `\n`、并加上首尾引号 → `systemSectionSizes()` 再也切不开分段，整块 system 被记成一段 `preamble`。后果：第 14 条那类"进程内 system 漂移"**根本没法定位到段**，只能看到 `changed:["system"]`；字节数也整体虚高（7142B 原文 → 7239B）

**确切命令序列**（复现/回归都靠它）
```bash
`npx vitest run custom/features/context/__tests__/prefix-fingerprint.test.ts -t '字符串原样返回'`
```

**怎么发现它（指纹）**
`prefix-fingerprints.jsonl` 里 system 相关记录只有 `preamble` 一段、`systemChangedSections` 恒为全部段名或空；`systemBytes` 比 `wc -c` 出来的 system 原文大（每换行 +1B）

**含确切语法的解法**
`systemTextOf()`：字符串**原样返回**，只有非字符串（结构化 content）才 `stable()` 序列化；测试同时钉住"保留真实换行"
