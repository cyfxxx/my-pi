# 失败模式：**多实例不可见（静默失效）**

**来源**：`docs/BUG-REPLAYS.md` 第 13 条（使用层面故障台账，代码检查全绿但用起来才炸）。

**是什么**
**多实例不可见（静默失效）**

**根因（WHY）**
`state-audit` 数实例的判据是 `argv` 里含 `cli.js`，而真 pi 启动后 `process.title='pi'` 把 `/proc/<pid>/cmdline` 覆盖成只剩 `pi` → 真机上实例数恒为 0/1（只有假 CLI 或启动早期才数得到），"多实例可见"这条承诺从上线起就没兑现

**确切命令序列**（复现/回归都靠它）
```bash
`node scripts/test-state-audit.mjs`（`process.title='pi'` 的假进程 + `cli.js` 形态各进程，断言 detected=3）；`node scripts/test-scenario-two-instances.mjs`（真链：断言实例数 ≥2）
```

**怎么发现它（指纹）**
两个 my-pi 明明同时在跑，`node scripts/state-audit.mjs` 却没有 `multiple-instances` 发现（或实例数不对）

**含确切语法的解法**
`scripts/state-audit.mjs` 的 `countRunningInstances()`：认 `cli.js` **或**标题 `pi`/`pi-rpc` 两种形态，且要求 `exe=node`、排除 `node -e` 助手
